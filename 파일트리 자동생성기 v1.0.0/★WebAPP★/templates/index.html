📁 파일트리 자동생성기 Web v1.0

개발자: 이재호

📋 저장된 템플릿

    🚀 파일트리 생성

    선택된 템플릿: 없음

    💡 사용법
    1. 왼쪽에서 템플릿을 선택하세요 (더블클릭으로 편집).
    2. 최상위 폴더 이름을 입력하세요.
    3. "파일트리 생성" 버튼을 누르면 ZIP 파일이 다운로드됩니다.
    4. 압축을 풀면 데스크톱 버전과 동일한 폴더/파일 구조가 만들어집니다.
    ※ 여러 사람이 같은 서버에 동시에 접속해 템플릿을 관리/생성할 수 있습니다.

    새 템플릿

    구성 (클릭: 선택 · Ctrl/Shift+클릭: 다중선택 · 드래그: 이동 · 더블클릭: 폴더 접기/펼치기 · 우클릭: 메뉴)
    💡 사용법
    • Ctrl+클릭: 다중선택
    • Shift+클릭: 범위 선택
    • 더블클릭: 폴더 접기/펼치기
    • 드래그: 항목 이동(폴더 위에 놓으면 그 안으로 이동)
    • 우클릭: 이름변경/삭제/접기펼치기
    • 불러온 파일은 실제 내용까지 템플릿에 저장되어 어느 PC에서 생성하든 그대로 복원됩니다.
