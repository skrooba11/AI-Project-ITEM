사용법

  • 업무내용을 입력한 뒤 START를 누르면 업무가 시작되고, 시작 전 입력한 업무내용은 종료 전까지 잠깁니다.
  • 작업코드가 CAD/ET/KT인 경우 MK번호(5자리 숫자 + M/T/R)와 공정명이 필요하고, KC/TT는 공정명만 있으면 됩니다.
  • END를 누르면 업무가 종료되고 오른쪽 표에 기록이 추가됩니다.
  • RESET은 저장 없이 현재 입력/진행 상태를 초기화합니다.
  • 즐겨찾기 버튼을 우클릭하면 자주 쓰는 코드/MK번호/공정명/업무내용을 저장해둘 수 있습니다.
  • 표 상단의 "전체 기록보기"로 오늘 기록과 전체 기록을 전환할 수 있고, 날짜 헤더를 클릭하면 정렬 순서가 바뀝니다.
  • 로그를 더블클릭하면 편집창이 열립니다. 여러 개 선택 후 삭제/엑셀 내보내기가 가능합니다.
  • 해야할 업무의 "중요" 칸을 클릭하면 목록 상단에 고정됩니다.
